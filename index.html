工地現場管理讓現場管理更有效率

從工程記錄、材料訂購到施工進度追蹤，所有現場資訊集中一處，隨時掌握全局。

核心功能
你需要的，全都在這。
工程記錄

月曆式日誌，一眼看清每日施工。

  • 記錄施工項目、樓層與出工人數
  • 月曆彩色點快速辨識記錄狀況
  • 支援工程記錄、材料訂單、備忘錄
工程進度

膠囊進度卡，各樓層進度一目了然。

  • 按工項 × 樓層個別追蹤施工進度
  • 引線日期直接連結對應施工記錄
  • 廠商出工人數自動統計彙整
案場資訊

計價表管理，合約進度即時掌握。

  • 記錄承攬總價、本工程與追加工程
  • 依廠商分別追蹤計價比例與進度
  • 一鍵開啟計價表明細
材料訂購

已選材料明細，快速確認訂購數量。

  • 購物車式介面快速勾選品項
  • 顯示歷史已訂數量供參考
  • 一鍵清空或傳送訂單
材料清單

材料清單管理，訂購流程更流暢。

  • 分類管理所有材料品項
  • 一鍵傳送訂單至 LINE 或試算表
  • 支援 Excel 批次匯入品項清單

使用教學

跟著以下步驟，5 分鐘上手「工地現場管理」。

快速入門

1
建立案場
開啟 App 後，點選右上角「＋」新增案場，輸入案場名稱、承攬總價與樓層資訊，即可開始管理該工地的所有記錄。
2
填寫每日工程記錄
在月曆頁面點選日期，記錄當天的施工項目、樓層與出工人數。月曆上會顯示彩色圓點，讓你快速辨識哪些日子已有記錄。
3
追蹤工程進度
切換到「進度」頁籤，依工項 × 樓層檢視膠囊式進度卡，點擊卡片可直接連結到對應的施工記錄，並自動彙整各廠商出工人數。
4
管理計價表
在案場資訊中輸入本工程與追加工程金額，依廠商查看計價比例與進度，點選即可開啟計價表明細。
5
訂購材料
進入「材料」頁籤，以購物車介面勾選所需品項並輸入數量，可參考歷史已訂數量，完成後一鍵傳送訂單至 LINE 或 Google 試算表。
6
管理材料清單
在設定頁分類管理所有材料品項，也支援使用 Excel 批次匯入品項清單，省去逐筆手動輸入的時間。
7
匯出與備份
工程記錄與計價表皆可匯出成 PDF 或 Excel 分享給他人。訂閱 Pro 方案後，資料會自動同步備份至您的 iCloud Drive。

Google Apps Script 設定說明

將訂單自動寫入 Google 試算表，只需幾個步驟即可完成設定。

步驟一：建立 Google 試算表

前往 Google 試算表，建立一個新的試算表，並記下試算表的網址（稍後用來部署腳本）。

步驟二：開啟 Apps Script 編輯器

在試算表中，點選上方選單「擴充功能」→「Apps Script」，開啟指令碼編輯器。

步驟三：貼上腳本程式碼

刪除編輯器中原有的程式碼，將以下程式碼完整貼入： 

function doPost(e) {
  var origin = "*";
  try {
    if (!e || !e.postData || !e.postData.contents) {
      return ContentService.createTextOutput(
        JSON.stringify({ "status": "error", "message": "無效的請求資料" })
      ).setMimeType(ContentService.MimeType.JSON);
    }
    var data = JSON.parse(e.postData.contents);
    var siteName = data.AM || "未指定工地";
    var items = data.items || [];
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getSheetByName("訂單");
    if (!sheet) {
      sheet = ss.insertSheet("訂單");
      sheet.appendRow(["日期", "工地名稱", "分類", "品項名稱", "數量"]);
      sheet.getRange("A1:E1").setFontWeight("bold").setBackground("#f3f4f6");
    }
    var formattedDate = Utilities.formatDate(new Date(), "GMT+8", "yyyy/MM/dd");
    for (var i = 0; i < items.length; i++) {
      var item = items[i];
      var cat = item.cat || "";
      var itemName = item.PX || "未知品項";
      var qty = item.SL || "未填數量";
      sheet.appendRow([formattedDate, siteName, cat, itemName, qty]);
    }
    return ContentService.createTextOutput(
      JSON.stringify({ "status": "success", "message": "訂單已成功寫入試算表！" })
    ).setMimeType(ContentService.MimeType.JSON)
      .setHeaders({
        "Access-Control-Allow-Origin": origin,
        "Access-Control-Allow-Methods": "POST",
        "Access-Control-Allow-Headers": "Content-Type"
      });
  } catch (err) {
    return ContentService.createTextOutput(
      JSON.stringify({ "status": "error", "message": err.toString() })
    ).setMimeType(ContentService.MimeType.JSON)
      .setHeaders({ "Access-Control-Allow-Origin": origin });
  }
}

function doOptions(e) {
  return ContentService.createTextOutput("")
    .setMimeType(ContentService.MimeType.TEXT)
    .setHeaders({
      "Access-Control-Allow-Origin": "*",
      "Access-Control-Allow-Methods": "POST, OPTIONS",
      "Access-Control-Allow-Headers": "Content-Type"
    });
}

步驟四：部署為網路應用程式

貼上程式碼後，依照以下步驟部署：

① 點選右上角「部署」→「新增部署作業」
在部署類型選擇「網路應用程式」。
② 設定執行身分與存取權限
「以哪個身分執行」選擇「我」；「誰可以存取」選擇「所有人」（含未登入者），這樣 App 才能無需登入即可寫入資料。
③ 點選「部署」並授權
系統會請您授予腳本存取試算表的權限，請點選「授予存取權」並以 Google 帳號登入確認。
④ 複製網路應用程式網址
部署完成後，畫面會顯示一組「網路應用程式網址」（格式為 https://script.google.com/macros/s/...），請複製保存，下一步會用到。

步驟五：在 App 中填入網址

開啟「工地現場管理」App，前往「設定」→「Google 試算表連結」，將上一步複製的網路應用程式網址貼入並儲存。完成後，每次傳送訂單即會自動寫入您的試算表。

常見問題

為什麼資料沒有寫入試算表？
請確認：① 網路應用程式網址已正確貼入 App；② 部署時「誰可以存取」已設為「所有人」；③ 已授予腳本讀寫試算表的權限。若修改過腳本，需重新部署（建立新版本）才會生效。
修改腳本後需要重新設定 App 嗎？
若只是修改腳本邏輯並重新部署（選「更新現有部署作業」），網址不會改變，App 不需重新設定。若建立全新部署，網址會不同，需重新貼入 App。
試算表可以改名或搬移嗎？
試算表可以改名，腳本是以 ID 綁定，不受名稱影響。但請勿刪除試算表，否則腳本將無法寫入資料。

常見問題

如何備份我的資料？
訂閱 Pro 方案後，資料會自動同步至您的 iCloud Drive。您也可以在設定頁手動觸發備份。
刪除 App 後資料會消失嗎？
訂閱 Pro 方案的用戶，資料儲存於 iCloud，重裝 App 後可自動還原。未訂閱用戶的資料僅儲存於本機，刪除 App 後將無法恢復。
如何恢復訂閱？
開啟 App 後，在付費牆頁面點擊「恢復購買」，系統將自動恢復您原有的訂閱狀態。
如何取消訂閱？
前往 iPhone「設定」→ 點選您的 Apple ID →「訂閱」→ 找到「工地現場管理」→ 取消訂閱。
免費試用期結束後會自動扣款嗎？
是的，試用期結束後會自動續訂並扣款。如不想繼續訂閱，請在試用期結束前取消。
匯出的 PDF 或 Excel 在哪裡？
匯出後會透過 iOS 的分享功能讓您選擇儲存位置，例如「檔案」App 或傳送給其他人。

隱私權政策

感謝您使用「工地現場管理」。本隱私權政策說明我們如何收集、使用及保護您的個人資料。

1. 資料收集

本應用程式以離線為主，所有工程記錄、案場資訊、材料訂購等資料均儲存於您的裝置本機或您的 iCloud 帳號中。我們不會在我們的伺服器上儲存您的個人資料。

2. 我們收集的資料

  • Apple iCloud：用於雲端備份與資料同步。
  • RevenueCat：用於管理訂閱狀態，適用 RevenueCat 隱私權政策。
  • Apple App Store：用於處理應用程式內購。

4. 資料安全

您的資料儲存於您的裝置本機或 iCloud，受 Apple 的安全機制保護。我們不會存取、傳輸或出售您的個人資料。

5. 兒童隱私

本應用程式不針對 13 歲以下兒童設計，亦不會主動收集兒童個人資料。

6. 隱私權政策變更

我們保留修改本隱私權政策的權利。重大變更時，將於應用程式內通知使用者。
